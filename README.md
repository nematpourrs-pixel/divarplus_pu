# دیوارپلاس | DivarPlus Android

**اپلیکیشن مستقل اندرویدی برای پالایش متنی آگهی‌های واقعی؛ با رابط وب متصل به سرور مالک.**

- Package: `ir.divarplus.app`
- Version: `1.1.0` (versionCode 2)
- Minimum Android: API 24
- Target SDK: API 36
- Server path: `https://YOUR-DOMAIN/divar_plus/`

## Build

GitHub Actions در این مخزن عمومی وظیفه بررسی ساخت `assembleDebug` و `lintDebug` را دارد. APK ساخته‌شده در این مخزن برای **آزمون** است و نباید در کافه‌بازار به‌عنوان نسخه Release بارگذاری شود.

**Release امضاشده صرفاً در مخزن خصوصی مالک** `divarplus_pr` با کلید مالک ساخته می‌شود. کلید امضا، گذرواژه‌ها و اطلاعات سرور نباید در این مخزن عمومی ذخیره شوند.

## Security

فقط دسترسی INTERNET؛ HTTPS اجباری؛ WebView Safe Browsing و سیاست منع دسترسی فایل؛ لینک‌های دیوار به برنامه/مرورگر خارجی هدایت می‌شوند.

## Important

اتصال زنده و مجاز به منبع آگهی‌های دیوار باید جداگانه روی هاست واقعی آزموده شود. این محصول وابسته یا مورد تأیید رسمی دیوار نیست. انتشار عمومی به تأیید کافه‌بازار و کنترل کیفیت عملی نیاز دارد.
