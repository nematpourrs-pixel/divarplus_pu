# دیوارپلاس | پروژه عمومی ساخت اندروید

مخزن عمومی مخصوص **ساخت APK اندروید** است و نباید حاوی رمز، توکن دیوار، تنظیمات خصوصی سرور یا فایل‌های PHP باشد.

## ساخت APK

در بخش **Actions**، گردش‌کار **Build DivarPlus Android APK** را انتخاب کنید و **Run workflow** را بزنید. فایل `app-debug.apk` در Artifact اجرای موفق قرار می‌گیرد.

در نخستین اجرای اپ، آدرس وب‌اپ نصب‌شده روی هاست را وارد کنید: `https://YOUR-DOMAIN/divar_plus/`.

سرور و خزنده در مخزن خصوصی `divarplus_pr` نگهداری می‌شوند. APK یک پوشش اندرویدی مستقل برای رابط دیوارپلاس روی سرور شماست و داده آزمایشی ندارد. اتصال به دیوار تا آزمون روی هاست شما تضمین نشده است.
